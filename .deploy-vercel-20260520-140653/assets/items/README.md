Coloque aqui as imagens dos Warframes e armas em formato `.webp`, `.png` ou `.jpg`.

Depois, preencha o campo `image` do item em `data/tier-list.json`, por exemplo:

```json
"image": "assets/items/mesa-prime.webp"
```

Tambem funciona com URL remota, por exemplo:

```json
"image": "https://cdn.warframestat.us/img/MesaPrime.png"
```

O site mostra a imagem no modo detalhado, no modal de detalhes e no recomendador por missao. Se o campo estiver vazio, ele usa um icone automatico com as iniciais do item.
